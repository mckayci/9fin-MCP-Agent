None was found, so no full workup was redone.
2. **Price move:** 9fin's MCP does not return Latest Price or Prior Week Price because of licensing. The latest 9fin European Weekly Stressed and Distressed Data Report is still the 25-Sep-26 edition used in the 27-Sep run, so no newer price evidence is available. Instrument-level moves need the 9fin web bonds/loans screener ("Prior Week Price Change" column).
3. **Screener behaviour (worth knowing for future runs):** the first natural-language query mapped "BB, B or CCC" to a partial Moody's list (Ba2, B2, Caa1-3) and exact S&P/Fitch grades, which returned only 9 names. Stonegate, Elysium, Punch and Intertek were dropped because their B3/B1/B-/BB-/B+ ratings were not matched. Re-running with every notch listed explicitly (Moody's Ba1 to Caa3, S&P/Fitch BB+ to CCC-) returned 13 names both times, and that is the result used here. Future runs should state the full notch range in the screener query.
4. **Status "priced"** is an instrument-level filter that is not supported on the company screener. Priced debt was confirmed via the cap tables in the 27-Sep run for 12 of 13 names. Elysium has no cap table on 9fin.
5. **Stale screener data:** Stonegate (the screener row is the legacy entity with LTM Apr-20, so current data comes from "Stonegate Pubs (New)"), Elysium (LTM Dec-21), Inspired (LTM Aug-22) and Victoria (LTM Mar-25). Where the screener and cap-table leverage bases differ, both are shown.
