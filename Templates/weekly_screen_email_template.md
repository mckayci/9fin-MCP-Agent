# Weekly Screen Email Template

## Greeting Rules
- 1 recipient: "Hi [First Name],"
- 2 recipients: "Hi [First Name 1], [First Name 2],"
- 3+ recipients: "Hi team,"
- If the recipient's first name cannot be determined from their email address, check `Templates/recipient_names.csv` for a stored mapping. If no mapping exists, ask Ciarán to confirm the name, then save it to the CSV for future runs.
